# Anapana Practice Checklist

A simple daily checklist to support your Anapana meditation practice.

## Pre-Practice Checklist ✓

### Environment Setup
- [ ] Found a quiet, distraction-free space
- [ ] Set meditation timer for desired duration
- [ ] Turned off phone/notifications
- [ ] Ensured comfortable room temperature
- [ ] Prepared comfortable seating (cushion/chair)

### Physical Preparation  
- [ ] Sat with back straight but relaxed
- [ ] Positioned hands comfortably (lap or knees)
- [ ] Relaxed shoulders away from ears
- [ ] Gently closed eyes or softened gaze
- [ ] Took 3 deep breaths to settle in

## During Practice Checklist ✓

### Core Technique
- [ ] Located breath sensations at nostrils
- [ ] Observed natural breathing without controlling
- [ ] Noticed cool air entering, warm air leaving
- [ ] Maintained attention at entrance of nostrils
- [ ] Avoided following breath into lungs

### Working with Distractions
- [ ] Gently returned to breath when mind wandered
- [ ] Avoided judging or criticizing distractions
- [ ] Used kind, patient attitude with myself
- [ ] Continued returning to breath repeatedly
- [ ] Stayed committed for full session duration

## Post-Practice Checklist ✓

### Ending Mindfully
- [ ] Concluded session with brief gratitude
- [ ] Wiggled fingers and toes gently
- [ ] Opened eyes slowly
- [ ] Sat quietly for a moment before rising
- [ ] Carried mindful awareness into next activity

## Quick Troubleshooting Checklist

**If feeling restless:**
- [ ] Check posture - is back straight?
- [ ] Accept the restlessness without fighting
- [ ] Return attention to breath sensations
- [ ] Consider shorter session today

**If feeling drowsy:**
- [ ] Sit up straighter
- [ ] Open eyes slightly
- [ ] Ensure good ventilation
- [ ] Try different practice time

**If mind very distracted:**
- [ ] Be patient with yourself
- [ ] Return to breath again and again
- [ ] Remember this IS the practice
- [ ] Continue for full session

**If experiencing doubt:**
- [ ] Remember benefits develop gradually
- [ ] Focus on consistency over perfection
- [ ] Review practice instructions
- [ ] Consider joining meditation group
