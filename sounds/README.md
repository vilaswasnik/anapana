# Audio File Placeholders

This directory should contain the following audio files for the meditation timer:

## Bell Sounds (Required)
- `tibetan-bell.mp3` - Traditional Tibetan meditation bell
- `singing-bowl.mp3` - Crystal or metal singing bowl sound  
- `soft-chime.mp3` - Gentle wind chime sound
- `temple-gong.mp3` - Deep temple gong sound

## Ambient Sounds (Optional)
- `forest.mp3` - Forest sounds with birds and rustling leaves
- `rain.mp3` - Gentle rain sounds
- `ocean.mp3` - Ocean waves and surf sounds  
- `white-noise.mp3` - White noise for concentration

## Audio Requirements
- **Format**: MP3 or OGG for broad browser support
- **Duration**: 3-10 seconds for bells, 5+ minutes for ambient (looped)
- **Quality**: 128-192 kbps for good quality and reasonable file size
- **Volume**: Normalized to consistent levels

## Sources for Audio Files
- **Free**: Freesound.org, Zapsplat, YouTube Audio Library
- **Premium**: Epidemic Sound, AudioJungle, Premium Beat
- **Record Your Own**: Use apps like Audacity to record real bells/bowls
