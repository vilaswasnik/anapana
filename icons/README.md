# Icon Assets for PWA

This directory should contain the following icon files for the Progressive Web App:

## Required Icon Sizes
- `icon-72x72.png`
- `icon-96x96.png` 
- `icon-128x128.png`
- `icon-144x144.png`
- `icon-152x152.png` (Apple touch icon)
- `icon-192x192.png`
- `icon-384x384.png`
- `icon-512x512.png`

## Additional Icons
- `meditation-icon.png` - For notifications
- `meditation-badge.png` - Notification badge
- `shortcut-10min.png` - 10-minute shortcut icon
- `shortcut-20min.png` - 20-minute shortcut icon  
- `shortcut-stats.png` - Statistics shortcut icon
- `play-icon.png` - Play action icon
- `clock-icon.png` - Clock/reminder icon

## Icon Design Guidelines
- **Style**: Minimalist, calming design with meditation theme
- **Colors**: Match app theme (primary color #6366f1)
- **Symbol**: Lotus pose, meditation pose, or breathing symbol
- **Format**: PNG with transparency
- **Background**: Either transparent or solid color matching theme

## Creating Icons
1. Design a master icon at 512x512 pixels
2. Use tools like:
   - **Online**: Favicon.io, Real Favicon Generator
   - **Software**: Adobe Illustrator, Canva, Figma
   - **Free**: GIMP, Inkscape
3. Generate all required sizes
4. Test on various devices and backgrounds

## PWA Icon Requirements
- Icons must be square (1:1 aspect ratio)
- Include both maskable and any purpose icons
- Consider safe area for maskable icons (80% of icon area)
- Test on Android (rounded), iOS (rounded square), Windows (square)

Replace this README with actual icon files before deployment.
